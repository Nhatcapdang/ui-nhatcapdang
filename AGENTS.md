# AGENTS.md

## Cursor Cloud specific instructions

This is a **Next.js 16 documentation site** (Fumadocs-based UI component library) with zero infrastructure dependencies — no database, no external services required.

### Quick reference

| Action | Command |
|---|---|
| Install deps | `yarn install` (also runs `fumadocs-mdx` postinstall to generate `.source/`) |
| Dev server | `yarn dev` (port 3001) |
| Lint | `yarn lint` |
| Type check | `yarn types:check` |
| Build | `yarn build` |
| Registry build | `yarn registry:build` |

### Non-obvious caveats

- **Yarn 4 via Corepack**: The repo requires Yarn 4.1.0 (`packageManager` field in `package.json`). Corepack must be enabled first: `corepack enable && corepack prepare yarn@4.1.0 --activate`.
- **`.source/` directory**: Generated by the `fumadocs-mdx` postinstall script. If it is missing or stale, run `yarn fumadocs-mdx` manually. Without it, the docs content won't compile.
- **Webpack bundler**: Both `dev` and `build` scripts use `--webpack` flag explicitly. Turbopack is not used.
- **Port 3001**: The dev server runs on port 3001 (not the default 3000).
- **No tests**: There is no test suite configured in this repository. Linting and type-checking are the primary automated quality checks.
